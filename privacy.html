Política de privacidad de EventMaps

Última actualización: 17 de noviembre de 2026.

EventMaps usa Firebase Authentication y Cloud Firestore para crear cuentas, mostrar negocios/eventos, favoritos, agenda, reseñas y solicitudes de negocios. Si autorizas la ubicación, se usa para centrar el mapa o fijar la ubicación de un negocio. Las fotos y comprobantes que un negocio envía se almacenan para la operación y moderación del servicio.

Los datos no se venden. Se comparten con proveedores necesarios para operar la app: Google/Firebase, servicios de mapas y, cuando estén habilitados, el proveedor de pagos elegido. La ubicación se solicita solo al usar una función que la necesita.

Conservación y eliminación

Puedes solicitar la eliminación de tu cuenta desde Mi cuenta → Solicitar eliminación. Se eliminarán tu perfil y datos asociados, salvo información que deba conservarse por obligaciones legales, prevención de fraude o registros de pagos. Para soporte escribe a rentafullmarket@gmail.com.

Seguridad

El acceso se controla con Firebase Authentication y reglas de Firestore. No envíes contraseñas ni datos de tarjetas por correo o chat.
